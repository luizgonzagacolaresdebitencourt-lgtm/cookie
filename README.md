# Cookie Demo

Aplicação simples que demonstra o uso de cookies em Node.js com Express.

## Como usar

1. Instale as dependências:
   ```bash
   npm install
   ```
2. Inicie o servidor:
   ```bash
   npm start
   ```
3. Abra no navegador:
   ```
   http://localhost:3000
   ```

## O que este app faz

- Define um cookie via formulário
- Lê os cookies atuais do navegador
- Apaga os cookies salvos
